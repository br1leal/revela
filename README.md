# Revela a Oito!

Jogo de perguntas escondidas palavra por palavra, para jogar em grupo (2 a 5 pessoas) numa tela só.
Inspirado no quadro "Respostas sem perguntas" do Roda de Bobo.

## Como rodar
É um arquivo único: abra `index.html` no navegador. Não tem build nem dependências além das fontes do Google Fonts.

## Deploy
- **Vercel:** importar o repositório como projeto estático (Framework: Other, sem build command, output = raiz).
- **Supabase:** ainda não está ligado. Veja `docs/HANDOFF.md`, seção "Dados e Supabase".

## Documentação
- `docs/HANDOFF.md`: estado atual, decisões de design, arquitetura e próximos passos.
- `CLAUDE.md`: regras de trabalho para o Claude neste projeto.
